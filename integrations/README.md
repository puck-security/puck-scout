# Puck Integrations

Third-party integrations for Puck.

## Planned Integrations

### TheHive (Launch)

Cortex analyzer and responder for [TheHive](https://thehive-project.org/). Allows TheHive cases to trigger Puck investigations and import findings as observables.

See [thehive/](thehive/).

### Tines (30 days post-launch)

Story templates for [Tines](https://www.tines.com/). Allows Tines workflows to trigger Puck investigations as part of automated response playbooks.

See [tines/](tines/).
